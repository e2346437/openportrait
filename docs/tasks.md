# Tasks

Shoots have a to-do list, so nothing between "booked" and "delivered" lives only in your head.

- **On a shoot:** the *To do* panel. Add a task with an optional due date, tick it off, delete it.
- **Tasks page** (sidebar): everything still open across your shoots, soonest due first, with overdue ones flagged. A *Done* tab keeps what you finished. Tasks on cancelled shoots are hidden.
- **Starter tasks** (Settings > Shoots > a shoot type > Tasks): the checklist every new shoot of that type begins with, for example "Send questionnaire" 14 days before, "Deliver gallery" 14 days after. Days count from the shoot's first date; leave it empty for no due date. Shoots you already have aren't changed, and a shoot with no date yet gets the tasks without due dates.
- Finishing a task adds a line to the client's timeline.
- **AI access:** `tasks_list` (read), `tasks_add` and `tasks_complete` (drafts, only the studio sees them), in the Shoots area.
